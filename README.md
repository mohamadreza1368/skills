# 🌟 مخزن مهارت‌های هوشمند برای دستیارهای هوش مصنوعی (Agentic Awesome Skills)

> **به زبان خیلی ساده:** فرض کنید یک دستیار هوش مصنوعی فوق‌العاده باهوش استخدام کرده‌اید که همه چیز را در سطح عمومی بلد است، اما روال‌های دقیق و ترفندهای حرفه‌ای پروژه‌ی شما را نمی‌داند.  
> این مجموعه مانند یک **کتابخانه با بیش از ۲,۸۰۰ دفترچه راهنمای تخصصی (Playbook)** است. هر زمان که دستیار هوش مصنوعی شما بخواهد کار خاصی (مثل تست امنیت، طراحی سایت، تحلیل داده یا رفع باگ) انجام دهد، دفترچه راهنمای مربوطه را می‌خواند و کار را دقیقاً مثل یک متخصص ارشد تحویل می‌دهد.

## 💡 این پروژه دقیقاً چیست و چه کار می‌کند؟

وقتی از مدل‌های هوش مصنوعی (مثل ChatGPT، کلود، جمینای یا ابزارهای کدنویسی مثل Cursor و Antigravity) می‌خواهید کاری پیچیده انجام دهند، ممکن است پاسخ‌های کلی، ناقص یا غیر استاندارد بدهند.

پروژه **Agentic Awesome Skills** مجموعه‌ای سازمان‌یافته از دستورالعمل‌های تست‌شده است که به دستیار یاد می‌دهد:
- اول کار چه سوالاتی بپرسد یا چه پیش‌نیازهایی را چک کند.
- مراحل را به چه ترتیبی جلو ببرد تا هیچ نکته‌ای از قلم نیفتد.
- از چه ابزارها و کدهای استانداردی استفاده کند.
- چطور خروجی نهایی را ارزیابی و اشکال‌زدایی کند.

---

## 🧩 مهارت یا Skill چیست؟ (به زبان ساده)

هر مهارت در این پروژه یک پوشه مستقل است که درون آن فایلی به نام `SKILL.md` قرار دارد. این فایل شامل:

1. **عنوان و کاربرد (When to Use):** به دستیار می‌گوید «چه موقع باید این راهنما را باز کنی؟» (مثلاً وقتی کاربر گفت من می‌خواهم دیتابیس را بهینه‌سازی کنم).
2. **گام‌های قدم‌به‌قدم (Workflows):** ترتیب دقیق کارهایی که باید انجام شود.
3. **نمونه‌ها و بهترین الگوها (Best Practices):** کدهای استاندارد و الگوهایی که هوش مصنوعی باید رعایت کند.
4. **محدودیت‌ها و هشدارها (Limitations):** خط قرمزهایی که دستیار نباید بدون اجازه کاربر از آن‌ها عبور کند.

## 🚀 چرا باید از این مهارت‌ها استفاده کنیم؟

* **عدم نیاز به پرامپت‌نویسی طولانی:** نیازی نیست هر بار کلی توضیح دهید که چه می‌خواهید؛ هوش مصنوعی فقط با یک کلمه یا اشاره به مهارت، استانداردترین مسیر را اجرا می‌کند.
* **کاهش خطاهای هوش مصنوعی (Hallucination):** چون مراحل کار از قبل تعریف شده، مدل رفتار سلیقه‌ای یا حدس و گمان بی‌مورد نخواهد داشت.
* **یکپارچگی کار تیمی:** همه اعضای تیم با یک دستورالعمل مشخص کار می‌کنند و خروجی‌های هوش مصنوعی برای همه یکدست خواهد بود.

---

## 🛡️ آیا استفاده از این فایل‌ها امن است؟

بله، این مخزن به طور کامل مورد ارزیابی امنیتی قرار گرفته است:

- **فایل‌ها کدهای مخرب نیستند:** فایل‌های اسکیل صرفاً فایل‌های متنی راهنما (`.md`) هستند و به خودی خود بدون دستور شما هیچ کاری انجام نمی‌دهند.
- **اسکن امنیتی خودکار:** تمامی ۲,۸۰۰+ مهارت توسط اسکنرهای امنیتی خودکار بررسی شده‌اند تا هیچ دستور مخرب سیستمی (مانند حذف فایل‌های اصلی ویندوز/لینوکس، دریافت اسکریپت ناشناس از اینترنت، یا دزدیدن پسوردها) در آن‌ها نباشد.
- **اصل حداقل دسترسی:** برای کارهای حساس (مثل تغییر دیتابیس یا اجرای کدهای سروری)، همیشه کنترل نهایی و تایید اجرا با خود شماست.

## 🛠️ چه ابزارهایی از این مهارت‌ها پشتیبانی می‌کنند؟

این مهارت‌ها با پرکاربردترین دستیارهای کدنویسی مدرن سازگار هستند:

| نام ابزار | نوع برنامه | نحوه فعال‌سازی |
| :--- | :--- | :--- |
| **Google Antigravity** | محیط توسعه و ایجنت هوشمند | اضافه کردن به پوشه `.agents/skills` یا اسکیل‌های محیط کاری |
| **Claude Code** | دستیار خط فرمان آنتروپیک | از طریق افزونه یا کپی در پوشه اسکیل‌ها |
| **Cursor** | ویرایشگر کد مبتنی بر هوش مصنوعی | استفاده با علامت `@skill-name` در چت |
| **Gemini CLI** | دستیار خط فرمان جمینای | دستور `Use <skill-name> to...` |
| **Codex CLI / Copilot** | ابزارهای کدنویسی هوشمند | فراخوانی مستقیم اسکیل‌ها |

## 📦 دسته‌بندی‌های اصلی مهارت‌ها (بسته‌های آماده)

اگر نمی‌خواهید بین ۲,۸۰۰ مهارت سردرگم شوید، می‌توانید از بسته‌های گلچین‌شده استفاده کنید:

1. 🌐 **توسعه‌دهندگان وب (Web App Builder):** مهارت‌های طراحی فرانت‌اند، ری‌اکت، ویو، نکست‌جی‌اس و ارتباط با بک‌اند.
2. 🎨 **طراحی رابط و تجربه کاربری (Product Design Studio):** مهارت‌های طراحی UI، دسترسی‌پذیری (Accessibility) و سیستم‌های طراحی.
3. 🔒 **مهندسی امنیت (Security Engineer):** بررسی کدهای ناامن، ارزیابی آسیب‌پذیری‌ها و سخت‌سازی برنامه‌ها.
4. 📊 **تحلیل داده و هوش تجاری (Data Analytics):** کار با داده‌ها، تحلیل کوئری‌های SQL و ساخت داشبوردهای آماری.
5. ☁️ **زیرساخت و دواپس (DevOps & Cloud):** داکر، کوبرنتیز، پایپ‌لاین‌های CI/CD و اتوماسیون سرور.
6. 🤖 **ساخت ایجنت‌های هوش مصنوعی (AI & MCP Builder):** آموزش ساخت دستیارهای تخصصی و ابزارهای واسط پروتکل MCP.

## 📥 چگونه مهارت دلخواه را نصب و استفاده کنیم؟

### روش اول: کپی مستقیم در پروژه خودتان (ساده‌ترین روش)
اگر از ابزارهایی مثل **Antigravity** یا **Cursor** استفاده می‌کنید:
1. پوشه مهارت مورد نظر را از فولدر `skills/` بردارید.
2. آن را در پروژه‌تان درون پوشه `.agents/skills/` یا `.gemini/skills/` قرار دهید.
3. هوش مصنوعی به صورت خودکار آن را شناسایی کرده و در کارهای مربوطه به کار می‌بندد!

### روش دوم: استفاده از پکیج منیجر (برای کاربران فنی)
اگر ابزار `npm` روی سیستم دارید، با دستور زیر می‌توانید پیش‌نمایش اسکیل‌ها را مشاهده کنید:
```bash
npx agentic-awesome-skills --skills brainstorming,systematic-debugging --dry-run
```

## ✏️ چگونه مهارت‌ها را برای تیم خودمان شخصی‌سازی (Customize) کنیم؟

این پروژه کاملاً بازمتن (Open Source) است. برای شخصی‌سازی:

1. **حذف مهارت‌های غیر ضروری:** مهارت‌هایی که به کار تیم شما نمی‌آید را حذف یا کنار بگذارید تا دستیار فقط روی استک شما تمرکز کند.
2. **اضافه کردن استانداردهای تیم:** فایل `SKILL.md` هر مهارتی را باز کنید و قوانین داخلی شرکت، معماری مورد تایید، یا ابزارهای داخلی‌تان را به آن اضافه کنید.
3. **فارسی‌سازی دستورالعمل‌ها:** می‌توانید توضیحات و پاسخ‌های راهنما را به زبان فارسی تغییر دهید تا دستیار با لحن و زبان دلخواه تیم شما خروجی بدهد.
